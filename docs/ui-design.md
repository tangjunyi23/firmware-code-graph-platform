## 本轮变化

- 安全工作台：首页改为可分析固件、进行中、待确认和会话总数；统计来自现有目录接口，不增加轮询。
- 发起分析：固件选择、任务输入、审批方式与快捷分析方向集中在一张表单中。
- 会话列表：按状态筛选、按会话或固件搜索；每页 6 条，保留原历史会话打开与新建会话逻辑。归档、停止等操作沿用左侧目录。
- 固件任务：新增状态概览与失败筛选，已选文件展示名称和大小，任务详情增加新建入口；切换任务时清理未提交附件。
- 报告中心：统一指标、档案列表、预览文档和导出操作的层次与间距。
- 导航与主题：补充收起导航的名称提示和当前位置标记，统一工作台深浅色令牌。

本轮为前端与文档调整，无后端运行代码变更。此前的输入面视觉改版、文案精简及对应测试同步提交；运行中的会话、发现和模拟工作区不纳入本次提交。
